# 发布准备记录

## 已具备

- 本地单用户流程：义项搜索、定义分支、循环提示、来源、已知集合、可达目标、最近探索与卡片导入导出。
- 外观和阅读设置按浏览器保存；卡片导入验证版本、义项和分支，失败不替换当前状态。
- 创建索引时校验三个输入文件，并使用临时文件替换索引；失败保留原索引。
- 有后端和前端单元测试、前端构建与格式检查，并提供 CI 配置。

## 公开发布前仍需完成

1. **数据许可和归属**：逐来源确认冻结包、外部词典和示例的使用、展示及分发权限，形成可公开的许可与署名记录。
2. **语义审核**：对义项、规则方向、完整前提和来源文本建立独立审核流程及可展示的审核状态；当前结构案例不是教学金标准，正方形案例已发现义项匹配问题。
3. **用户研究**：以目标用户和明确任务检查是否能辨认识别义项、解决阻塞及理解解释，记录失败和可访问性问题；当前没有学习效果实验。
4. **公开服务工程**：明确部署架构、用户隔离、身份认证、数据备份恢复、故障处理、安全审查及监控。当前只允许本机单用户使用。
5. **持续交付与兼容性**：在干净环境运行 CI，并覆盖真实浏览器的窄屏、键盘和辅助技术；测试不同数据版本及备份恢复。配置 CI 不等于实际 CI 通过。

这些项目需由相应的数据权利人、审核人员和真实用户参与，不能通过界面调整或结构测试单独完成。
