## 🛠️ 技术实现方案

### Task 1: 语义社区发现

**算法选择**: Louvain算法（适合大规模网络）

**输入**：
- 展平的依赖图（head → dependencies）
- 可选：加入超边权重（依赖频次）

**输出**：
- 每个节点的社区归属
- 社区的模块度得分
- 社区内Top节点
- 社区可视化

**实现步骤**：
1. 将超图转换为加权无向图
2. 使用python-louvain或networkx运行Louvain
3. 计算社区统计指标
4. 选取5个代表性社区进行语义标注
5. 生成社区网络可视化

**预期结果**：
- 15-30个主要社区
- 模块度 > 0.4（说明社区结构明显）

---

### Task 2: 关键路径分析

**选择典型概念**：
- 从不同深度层抽样（50层、150层、300层、350层）
- 包含不同词性（名词、动词、形容词）
- 包含高频使用的概念

**分析维度**：
1. **路径长度**：从basis到目标的最短/最长路径
2. **路径多样性**：有多少条不同的推理路径
3. **瓶颈节点**：路径中频繁出现的中间节点
4. **路径共享度**：不同目标概念的路径重叠程度

**可视化方案**：
- 使用Graphviz生成推理树
- 节点按层次纵向排列
- 用颜色区分basis、中间节点、目标节点
- 高亮瓶颈节点

**实现工具**：
- NetworkX: 最短路径、所有简单路径
- Graphviz/PyGraphviz: 可视化
- 自定义BFS追踪算法

---

### Task 3: 循环依赖分类

**分析维度**：

1. **按长度分类**：
   - 短循环（2-5个节点）
   - 中循环（6-15个节点）
   - 长循环（16+个节点）

2. **按涉及节点类型**：
   - 纯介词循环
   - 介词+实词混合
   - 纯实词循环

3. **按强连通分量**：
   - 使用Tarjan算法识别所有SCC
   - 统计SCC大小分布
   - 分析大型SCC（>10个节点）

4. **语义合理性**：
   - 抽取100个代表性循环
   - 人工标注：合理/可疑/明显错误
   - 总结模式

**输出**：
- 循环分类统计表
- 典型循环案例库（10-20个）
- SCC可视化（选取3-5个有代表性的）

---

### Task 4: Hub节点深度分析

**分析Top 100入度节点**：

1. **语义类型标注**：
   - 自动分类：介词、连词、系动词、实词
   - 细分：空间关系、时间关系、因果关系、属性等

2. **质量风险评估**：
   - 检查定义的完整性
   - 检查是否在循环中
   - 检查下游影响面（被多少概念依赖）

3. **与Basis关系**：
   - Hub中有多少是Basis原子
   - 非Basis Hub的推理深度

4. **生成审核清单**：
   - Top 20高风险Hub节点
   - 审核优先级排序
   - 每个节点的问题描述

**输出**：
- Hub节点语义类型分布表
- 高风险节点清单（Excel/CSV）
- Hub节点网络可视化

## 🚧 潜在风险与应对

### 风险1: 计算时间过长
- **风险**: Louvain算法在大图上可能耗时
- **应对**: 先在子图测试，考虑使用并行计算或采样

### 风险2: 可视化复杂度高
- **风险**: 大型推理树难以可视化
- **应对**: 限制显示深度，只展示关键路径

### 风险3: 循环过多无法全部分析
- **风险**: 49K个循环无法逐个分析
- **应对**: 分层采样，优先分析短循环和高频循环

### 风险4: 语义标注主观性
- **风险**: 社区和Hub的语义分类可能不准确
- **应对**: 结合词性、定义关键词自动分类，辅以抽样人工验证
