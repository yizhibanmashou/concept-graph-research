# 介词匹配对照的分层诊断

此分析在看到总体匹配对照结果之后提出，属于事后描述。复用介词种子 17、非介词种子 100–119，同一冻结图和精确目标使用频数匹配方式；按目标的来源目录、词性及原始不同分支数（1、2、3 条及以上）分层，报告各层总目标数、发生删除的目标、非空碰撞目标、新空分支目标。每个目标只落在一个层，分母分别明确，不将“所有目标”和“发生删除的目标”混用。

不同对照在各层删除涉及的目标不相同；分层后仍不能消除词形、释义、来源构造规则和依赖组合的混杂，也不能进行语义或因果推断。细层样本少可能造成不稳定；不按结果事后挑选显著层。单图、共享节点的重复抽样并非独立语料。输出存本机忽略的 outputs，记录冻结输入摘要。
