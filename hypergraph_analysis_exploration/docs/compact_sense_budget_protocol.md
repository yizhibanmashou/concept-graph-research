# 紧凑别名表示与完整分支预算：事后试点

在观察原始 JSON 的候选预算损失后，探索用候选内部短别名代替反复出现的长义项 ID。目标 ID 由候选检索系统在模型输入外保留；每个选中依赖按原 ID 排序分配 `d0`、`d1` 等别名，依赖清单中同时保留别名及其完整 gloss。B 为依赖清单，C 加从当前目标出发的成对边别名列表，D 加由同样别名组成的完整分支。C 的 head 是当前候选，方向由 schema 固定；没有角色标签。外部原始记录与被选分支索引可恢复别名到原 ID 的映射。不同候选的别名只在各自内部有意义，不是跨候选共享的语义身份。

在同一 40 个探索目标、同一 BERT 词表和 128/256/512 候选 token 门槛下，沿用原分支顺序贪心选择整条分支：只有 A/B/C/D 的新序列化均在预算内才接受。与旧长 ID JSON 方案报告全部／部分／零分支保留目标数及保留分支总数；不存在上下文拼接、模型准确率或语义质量测量。两种表示包含相同已选依赖及分支结构，但文本表面形式不同；并未证明两者对编码器等价。观察开发试验后提出方案，属于事后方法探索，不能称独立验证或最优方法。
