# A–D 共同候选预算的完整分支装配试点

目的：在候选部分限定 token 预算时，能否为 B、C、D 保留同一组完整分支的依赖，同时避免对 JSON 做中途截断？本试点不包括上下文，不是模型评测或最优选择算法。

对每个目标按冻结图既有分支顺序贪心处理，每次尝试增加整条原始分支；由被选分支的依赖并集重建 B 的释义清单、C 的成对边和 D 的分支，再分别编码 A–D 的紧凑排序 JSON。只有四种表示均不超过同一个预算时接受该分支，否则跳过；不保证所选分支数量最优，不依据测试标签或模型效果选择。若连空分支集合的共同基础表示都超预算，记录为基础不适配；若无任何分支入选，记录为无结构分支，不作合格结构样本。

对相同的 40 个探索义项分别以候选预算 128、256、512 测试，使用固定 BERT uncased WordPiece 和特殊 token。报告所有分支完整保留、部分保留、无分支及基础不适配的目标数，统计所选与原始分支数。分支顺序影响贪心结果且没有语义角色真值；只有“保留了完整输入分支”这一结构事实，不保证语义忠实。上下文及其他任务标记将进一步消耗模型总预算，不能把本结果当作正式 WSD 性能或所有模型的适用方案。
