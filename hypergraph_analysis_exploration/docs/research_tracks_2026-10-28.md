# 研究支线与实验计划（2026-10-28）

## 已有证据：介词筛选不是删去介词路径

冻结图包含 110,425 个节点、154,206 条 AND 子句和 85 个 basis；这些数字来自已有汇报，应以冻结包和复现结果为准。`outputs/weekly_experiment_2026-10-20/preposition_filtered_screen.json` 在固定的 1,200 discovery 根上排除含 prep 成员的候选对，并在不重叠的 3,000 evaluation 根上统计支持、审计直接父节点；未删除介词节点及其路径，也未重新计算随机化显著性。原 k=3 top 20 有 8 对含 prep，筛选后符合原阈值的候选数 6,182。新第一名 `prevail / hold / obtain` 与 `sphere / domain / area / orbit / field / arena` 在 evaluation 的 382 个支持根全部由同一 prep 父节点 `in-6` 直接带出：只过滤对的端点无法消除上游介词造成的共现。

触发问题的关键是定义：介词可能是无内容的连接符，也可能携带方向、空间、否定或角色信息，不能一概删去。`without` 的手工接口正是一个反例。现有结果建立在固定 selected witness，不代表所有备选路径或已验证词义。

## 下一个可复验的介词消融

1. 先锁定数据 manifest/hash、selected witness、根集合和深度（k=2、3、4）；记录 prep 标注口径，清点词性及介词的入度、作为中间节点的路径覆盖，人工审核高影响节点。
2. 保持根和统计方式不变，分别测：原图；只过滤候选端点（现有口径）；在到达 prep 时截断、保留它为显式未解析边界；以及经人工审核的关系化替换（保留角色/方向/否定、来源与备选分支）。不能直接移除 AND 前提后把剩余部分视为完整定义，否则会扩大闭包、改变含义。
3. 报告前沿大小、prep 途经率、候选支持、排名变化、直接父节点集中度和不同来源家族数；分层匹配根/词性，展示覆盖损失和受影响样本。每种规则保留独立图快照和 provenance，避免覆盖冻结数据。
4. 用 discovery 选候选，在独立 evaluation 根重新拟合保留行列边际与词性分层的随机化基线，报告置换数及 Holm 校正；再按来源家族留出、核查共享祖先及模板。深度之间固定同一候选或说明各自筛选偏差。
5. 对候选随机抽样独立双人标注语义关系、否定/方向和证据，报告一致性及不确定性。更干净的统计分布不等于更正确的语义。

## 有意思的应用与优先顺序

- **来源感知概念组合浏览器**：列出共现根、独立父定义数量、代表路径和介词途经标记，用户能比较“高频”和“跨来源”。这最贴近已有产物，先做只读原型；它是发现工具，不声称新概念。
- **反向词典**：用户描述检索候选，再用角色、方向和完整分支重排；对角色反转、否定、缺失条件构造独立人工测试。MultiRD 论文使用词典释义及人工描述评测：https://ojs.aaai.org/index.php/AAAI/article/view/5365 。结果按义项及词形分别报告 MRR、Recall@K、Top-1。
- **义项表示与 WSD**：用义项作为单位，比对同编码器、相同预算的 A 原 gloss、B gloss 加依赖文本、C B 加普通边、D B 加完整分支与可用角色。固定数据划分、输入预算、调参与计算量；报告总体与低频/未见义项，以及资源映射覆盖率与无法映射情况。已消歧依赖是候选知识，不要求上下文逐字包含所有前提。释义双编码器已有长尾 WSD 研究：https://aclanthology.org/2020.acl-main.95/ 。现代 LLM 对照也有必要：https://aclanthology.org/2025.emnlp-main.1720/ 。FEWS 义项来自 Wiktionary，须先建立并审计跨资源映射，不能假定与 OEWN 一一对应：https://nlp.cs.washington.edu/fews/ 。
- **词汇替换与翻译**：后续验证角色和上下文是否改善实际用词；需要额外控制语法搭配和错误消歧传播。依赖边不是上下位蕴涵边。

A–D 必须匹配依赖信息及截断策略；D 与 C 之间只有结构编码不同。固定候选池，测试句与标签不参与图纠错、训练或调参。优先做小规模可复现试验，不宣称已有效。

## ToLogic 模型支线

六例作为有限语法回归集，不作为模型泛化测试；记录输入结构、AST、完整候选集与 reference 的来源和哈希。模型任务可定义为给定定义及经审定的接口，从枚举候选中排名：先用规则或简单文本相似度基线，再比较同预算模型；指标包括 Top-1、MRR、正确式召回和作用域/角色错误。按义项及构式家族留出，禁止把 expected 答案或同义变体泄漏到输入和调参；六例仅能做可行性演示，需另建独立人工核验样本。接口约束、有限搜索完备性与语义正确性分别报告。

`want` 只有一个手工 `be without` 分支；`without` 为外部 LHS 假设，不是 85 basis 中的冻结词，不能将其 RHS/语义视为已验证。建议先由领域人员独立审定接口、角色和标准公式，再分别增加其他定义分支，记录义项、资源清单和输入更改；新增正确式不可从已生成候选逆向挑选后声称独立金标准。
