## 总问题和共同门槛

研究总问题：保留定义中的 AND 联合构造、OR 替代路径和可复用中间概念，是否比原始释义和普通成对词义关系，为机器理解及人类概念发展带来额外有效信息？结构、语义正确性、模型性能和认知解释是不同证据层级。允许结论为无增益或证据不足。

所有工作都要有冻结输入摘要、可复现命令、样本/分母、失败分类和数据许可记录。测试标签不可参与候选生成、调参或纠错。原始 OEWN 包和私有模型/审阅材料只在本机。科学问题、数据风险、需新许可或参与者研究的任务遇到门槛时暂停，不用工程代理指标替代。

## PR 拆分和执行顺序

1. **T02**：协议门槛补齐（样本总体、来源、盲化和精度）→ 正式人工标注包/保真审查 → 依据实际标签分析删除、保留和类型化方案。方法选择和重要解释提交负责人把关。
2. **T04**：预算与候选构造协议 → 新数据/来源许可审查 → 冻结实现与配置 → 新 dev/测试一次评估。任何长度匹配方案须同时报告信息损失和公平性，不按旧 dev 分数选择。
3. **T01**：协议/导出模板 PR → 人工标签仅本地受控保存 → 在标签与样本充足后单独设计排序比较。当前分支不得带入案例材料或标注结果。
4. **T05**：许可与测量盘点 PR → 小样本映射可行性 → 若 gate 通过，再开独立预测实验 PR。
5. **T03**：小型可用性修复按主题 PR；真实人类实验不和一般 UI 工程 PR 混合。

一个 PR 只做一个可独立审阅的问题。PR 描述记录问题、假设、数据/代码版本、操作、结果、失败、限制、复现方法和下一项任务。用户已授权工程检查无误后可不要求 1 人批准直接合并；这不覆盖科学方向、许可、参与者研究或数据解封决策。
