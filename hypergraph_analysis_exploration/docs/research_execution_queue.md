## 总控问题与证据级别

**核心问题：** 保留定义中的联合构造（AND）、替代分支（OR）与可复用中间概念，是否比原始释义或普通成对关系，为机器语义理解与人类概念习得提供额外信息？

所有结果必须注明证据层：结构描述、模型工程/表示结果、独立语义结果、或人类认知结果。前一层不能替代后一层。所有支线保持一个主题一个分支/PR；数据、报告、checkpoint 和冻结 OEWN 不入 Git。用户已允许在检查无误后不强制 1 人批准并直接合并；但科学决策仍由用户把关，工程 CI 不能代替科学授权。

### Q1 — T02 全量影响框之后的来源 crosswalk（当前主任务）

**已具备的可复核证据**

- 分支回链：145,991 条活动分支、146,134 条来源引用；全部引用绑定到已核验的同目标 payload。140,170/146,134 条引用 raw definition exact-match；140,109/145,991 条分支至少有一个 exact-match 来源；101,753/104,907 个目标满足每条活动分支都有 raw-exact 来源，98,323 个目标满足 effective-exact 口径。3,133 个整体 raw gloss 命中目标未达到全分支覆盖。
- raw definition 与固定 OEWN 2025 Plus 释义精确匹配：104,886；未匹配 21。effective definition 精确匹配 101,354、非空不同 3,553。
- `prep` 删除影响 84,976/104,907 个目标；删除 198,543 个 occurrence，改变 116,616/145,991 个分支，生成 358 个新空分支；462 个目标有新增非空碰撞，collision excess 566。

- 当前分支回链聚合产物仅在 ignored `outputs/t02_full_oewn_prep_overlap_lineage_20261031.json`，SHA-256 `571937a72af641d606034cb39d45bb8d15ceff30245627ee1cb878d5d3fd8082`。它提供 clause→payload 身份回链和释义字符串覆盖，不是 source-family 独立性、结构权利或语义保真证据；101,753 是候选覆盖总体，尚非负责人批准的正式抽样框。

**下一动作**

1. 标签级来源排查与既有资源专项结果已整理为 [`t02_source_family_crosswalk_status_2026-10-31.md`](t02_source_family_crosswalk_status_2026-10-31.md)。5,625/5,625 条 payload 重读成功，3,645 项/82 个标签；只有 17/82 个标签与本地权利日志唯一规范化匹配，涉及 2,395/3,645 项。类型化关系字段覆盖为 0/3,645，因此来源元数据本身不能自动支持空间/位置、方向/路径、参与者角色、否定/缺失分类；关系证据不足必须保持 `unresolved`。GCIDE 归档和部分图 witness、MeSH/OLS 查询快照存在更强的局部内容/身份链接，但仍不覆盖全部 occurrence、不证明语义支持或清权；逐记录 source-family crosswalk 仍未完成。另核对生成边界：当前冻结包只含 `tools/read_graph.py`，没有 source-evidence producer；本地 source records 保留的旧 producer 根路径也不存在于当前工作区。恢复历史只提供 `Wn2Lingua/KaikkiBasisHeldoutEvaluation` 标签，producer 实现哈希及所引用输入缺失。因此不能把 pipeline 标签/旧路径提升为已复现来源链；按当前工作区证据仍保留 `source_unresolved` 并停止确认性抽样。
2. 官方 OEWN 仓库说明 2025 Plus 发布版于 2025-12-31 发布，并将 OEWN 许可标为 CC BY 4.0；其 license 文件要求对 Princeton WordNet 与 OEWN team 署名。CC BY 4.0 还要求提供合理署名、许可链接并说明修改。对 raw gloss 与发布版精确匹配的目标，这提供了一个可追溯的释义文本使用路径；它**不自动清除**混合来源冻结 payload、图规则或其它嵌入材料的权利，也不证明结构分解来自该条 OEWN 释义。外部依据：[OEWN 仓库](https://github.com/globalwordnet/english-wordnet)、[OEWN LICENSE](https://github.com/globalwordnet/english-wordnet/blob/main/LICENSE.md)、[CC BY 4.0 条款](https://creativecommons.org/licenses/by/4.0/)。
3. 从可确认的上游记录建立 `target → graph rule/source occurrence → source payload → 原始 provider/release/version → license/attribution → source family` crosswalk；精确 OEWN 释义命中单独记录，不能据此推断 frozen payload 的唯一上游来源或具体 rule 的来源。
4. 为 crosswalk 增加互斥失败类别：`exact_release_match`、`normalized_only`、`different`、`missing_identity`、`source_unresolved`、`rights_unresolved`。只输出聚合结果和哈希；标识符/释义仅在本机访问受控材料中使用。

1. 检查当前分支、远端 head、未提交变化、PR/CI 实际状态和 ignored 产物边界。
