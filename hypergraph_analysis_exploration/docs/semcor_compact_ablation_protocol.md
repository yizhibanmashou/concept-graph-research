# 紧凑表示在开发集上的后续诊断

此实验在观察长 ID A–D 开发集结果及 40 义项的紧凑预算试点后提出，属于事后探索。沿用同一 SemCor 开发文档、表面词形、语料 POS、OEWN 候选和 BERT 词表；不读取保留测试集。只更改候选内部序列化为局部短别名，按与原方案相同的候选侧 256 token 门槛和贪心顺序装配完整分支；C 的 head 为当前候选，D 的别名保留分支成员关系。每组仍用 BM25 词袋排序，先预测再读 gold。

比较 gold 候选全部／部分／零分支、同一候选覆盖实例 A–D 词面正确数及成对 A/D 差异。短别名同时改变序列化文本、ID 信息及能保留的分支数量，因此与长 ID 的结果之间存在混杂；BM25 无法理解结构，不能据此归因“结构有效”或评估神经模型。共同预算仅限候选、不包含上下文。开发集已经用于纠错和方案设计，不是独立确认集；保留测试不用于方案选择。
