### 3. 分析交互式概念词典方案

该线程包含知径产品化工作，以及 HTE 首次引证日期试连图节点的探索。HTE 年代是词形/词义的最早已知引证，不等于概念诞生或儿童习得时间；surface form、POS 与 sense 映射会引入歧义。知径已有搜索、路径、分支选择、循环处理和设置等产品功能，但工程功能不代表来源语义正确或用户学会了目标概念。

**当前状态：**现有 Demo 保持为唯一实现，不另建替代品。本轮重新核验后端 14 项、前端 9 项和构建；仅支持合成用例和构建结论。当前用户禁止 Computer Use，因此真实 UI/窄屏/键盘人工走查暂不执行；需使用非 GUI 自动化或等待用户改变限制。HTE 结果维持探索性，不写入冻结图，也不转作认知标签。

### 4. 规划超图分析路线 (2)

该线程澄清了 discovery/evaluation 根节点不重叠不等于展开内容、祖先和来源家族独立。共现支持率是共同出现根数除以根总数；富集倍数相对保留根大小、概念频率和 POS 的随机基线，不控制共享定义模块。三种来源形态来自挑选案例，不能据此声称覆盖多数候选。

**当前状态：**这些解释边界已保留在结构实验报告与路线图。k=2/3/4 的发现/评估结果支持“特定候选超出指定随机基线”，不支持“新概念组已发现”。共享直接父节点或更早祖先可以解释一部分强共现；来源解释不是唯一因果机制。

### 5. 规划超图分析路线 (3)

该线程将研究定位从单纯“高支持共现”推进到“来源感知概念组合发现”，建议把候选写成带目标义项、语义关系槽位、原始释义和来源路径的实例，而不是只判断无序概念对。k=3 是目前较适合作为语义审查主层的工作选择；k=4 更适合分析模块传播，k=2 可作浅层参照。此前提出的约 120 条语义核验材料是设计建议，不等于已获授权或已完成标注。

**当前状态：**这一定位保留为总研究目标，但不能在来源家族、许可与独立抽样框未解决时启动正式标注。关系槽位可用于下一版 schema 的研究设计，标签体系与估计量仍按用户已明确的 T02 三轴和目标等权决定，不用旧 120 条建议覆盖现有协议。

## 统一判断

目前能够支持的主张是：超图中的某些概念组合在指定随机基线下呈现富集；部分强共现可追溯到反复使用的定义模块或祖先路径；T04 的全候选、修正 C 和 XPU train-only 训练链可运行、可重放；知径固定合成任务和 API 路径可检查。**当前没有证据确认完整 AND/OR 构造相对普通释义和成对关系带来独立的 WSD 收益，也没有人类概念学习收益证据。**

所以近期优先级仍是：T02 来源身份/权利/家族 crosswalk 与独立语义保真可行性；T04 独立开发语料及泄漏、映射、候选与共同预算协议；同时维护 T01/T03/T05 的可审计小里程碑。未通过数据或人工资源 gate 时，诚实交付数据可行性或失败分析，不用扩大模拟实验来替代缺失证据。
