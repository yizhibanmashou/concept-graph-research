版本：v1.0

## 1. 研究总问题

项目要回答：

> 保留词典定义中的联合构造结构（AND）、替代路径（OR）和可复用中间概念，是否比原始释义、普通词义关系图和成对依赖图，为机器语义理解及人类概念发展提供额外的有效信息？

答案允许为“在限定条件下有效”“当前方法未见可靠增益”或“证据不足”。研究流程不以得到正向结果为目标。每项主张分成四类证据：

1. **结构事实**：冻结输入上的节点、分支、路径、碰撞、可达性和计算统计。
2. **表示事实**：特定序列化、编码、预算和模型是否按协议工作。
3. **语义事实**：独立标注或外部有效标准是否支持某条释义关系、方向、极性或候选义项。
4. **认知事实**：独立的人类行为或习得数据是否支持关于人类学习的解释。

这四类证据不互相替代。依赖可达性不是自然语言蕴涵；结构深度不是学习难度；模型在小型开发集上的分数不是独立测试结果；模拟器中的缓存收益不是人类认知规律。

## 4. 共享科研协议

每个新实验开始前必须在对应 `docs/` 协议中写清：

- 可反驳的研究问题、主要比较和估计对象；
- 冻结数据包版本、来源、许可状态、输入路径摘要、样本框、切分及排除规则；
- 处理条件、对照条件、共同样本、共同信息和共同预算；
- 模型/算法版本、运行环境、随机种子、训练预算及推理规则；
- 主要与次要指标、误差/区间估计、分层方案、多重比较和停止门槛；
- 测试隔离、语义标注与裁决安排、失败输出和记录位置；
- 代码、配置、报告和 PR 的单主题边界。

一次结果目录至少记录：命令、脚本/配置版本、输入摘要、运行环境、种子、开始/结束状态、分母、排除原因、失败例、机器输出和可重放命令。缺失值、无法映射、零分支、超预算、推理失败必须保留原因，不能静默丢弃或计为模型成功。

模型比较需区分“同一最大 token 上限”和“同等实际计算量”。除最大长度，还要记录候选数、实际 token、padding token、优化步数、峰值显存、训练/推理耗时；如果不能匹配实际计算成本，就报告差异，不声称严格等算力。

## 5. 五条支线的分阶段路线

### T01 · ToLogic：词典知识约束的逻辑编译

**问题：** 在释义、已审定概念接口和构造分支给定时，如何生成可追溯、类型正确且语义可接受的逻辑公式？

**阶段：**

1. **冻结回归与数据契约（准备）**：重放六例 455 候选和 want 130 候选；锁定输入、接口、构式、AST、候选全集与参考来源。want 的 `without` 保持外部接口状态，不并入 basis。
2. **盲审校准（门槛）**：人工审定动词论元、语义角色、量词、否定、作用域与公式等价准则；六例只做有限语法回归，不能当成泛化测试。现有 want 20 例审阅框先用于说明书试标，独立标注、分歧和仲裁均须保留。
3. **候选排序（协议通过后）**：在同一有限候选集上比较可解释规则基线、轻量文本/小模型排序；按义项和构式家族留出。不得从模型输出逆向挑选 gold。
4. **独立验证（扩展数据到位后）**：分别报告合法语法、参数绑定、参考候选召回、人工语义可接受率、公式等价与可执行证明；LLM 评审只能辅助分歧检查，不能代替人工或执行验证。

**首个 PR 工作单：** ToLogic replay/接口盘点可以作为独立代码与文档 PR；人工标签、释义源文或压缩包不能被带入 Git。只有在标签流程与授权通过后，再单独开排序 PR。

**验收与停止：** 六例可复现候选集；want 的 RHS、角色和语义有经审定记录；语法、绑定、语义分轴指标可重算。没有独立语义标签时，停在“枚举/工程可行性”，不得报告准确率或模型泛化。

### T02 · 介词与概念组合：从删除转向关系保真比较

**问题：** 介词作为节点在多大程度上造成结构扩散？哪些用法是关系/角色/方向/极性信息，怎样表示才能去掉冗余连接同时保留定义内容？

用户已确认目标等权估计：对每个目标先计算其全部可审查 OR 分支的标签比例，再跨目标宏平均；另报告“全部分支均保真”的目标比例作为严格次要指标。

#### T02 阶段和首轮实验

1. **统一四条件（T02-0 已合并）**：同一目标、OR 分支、输入版本、展开口径与深度，比较原图、POS 删除、未解析边界保留、经来源支持的关系类型化。`prep` 为主口径，`prep_phrase` 单独敏感性；空分支显式标记，禁止当作无条件事实。
2. **关系记录格式（主要口径已由用户确定）**：消融主口径为 `pos=prep`，`prep_phrase` 单列敏感性分析；关系类型限有来源支持的空间/位置、方向/路径、参与者角色、否定/缺失，保留有序论元及原 occurrence。证据不足时标 `unresolved`，不得从介词字符串自动推断类型或角色。`without` 的图义项与 ToLogic 外部接口分开。
3. **盲审样本框**：用户已决定现有 40 条只作手册和流程试标，正式样本必须独立抽取。按来源家族留出独立目标与分支，分层记录关系功能、方向/否定、碰撞、新空分支、未受影响对照，保存抽样概率和总体分母。两位审查者独立判断方向/论元、否定范围、内容遗漏/添加及整体保真，保留无法判断并由第三人仲裁。先核对版权、授权和可公开字段。
4. **先报描述性结构结果**：目标/分支变化、新空分支、非空碰撞、未解析率、闭包可达率、共同可达目标深度、边界覆盖、来源家族数与排名变动。不同分母和可达子集必须单列。
5. **结构变化与定义保真作为并列估计目标**：用户已选择并列报告，不将二者合成单一总分，也不以结构简化代替语义改善。结构侧报告目标/分支变化、新空分支、非空碰撞、闭包可达率等；定义保真侧在样本/协议门槛达到后，报告独立双人标签、一致性、完整标签分布及区间，并比较四条件的信息保存/丢失。若关系标注许可、盲法、来源隔离或转换映射失败，停止确认性语义评估，报告未覆盖与失败原因。

#### T02 预定 PR 切分

| PR | 内容 | 验收条件 |
|---|---|---|
| T02-0（已合并） | 四条件共同协议、并列估计目标、用户决策记录 | 不改冻结图；每项指标有分母与解释边界；只包含可公开设计 |
| T02-1（本轮） | 用户已决关系类别、unresolved 与人工保真字段/盲审协议 | 不处理真实图或标签；明确已决与待决项、估计单位及样本精度 gate |
| T02-2 | 纯合成记录 validator 与只读转换器 | 每条转换可追溯原 occurrence/分支；无隐式删除、方向丢失或空前提变事实 |
| T02-3 | 经许可核验的独立盲审 frame 与呈现工具 | 试标样本与正式样本隔离；随机匿名呈现、支持不确定与仲裁、抽样分母可复算 |
| T02-4 | 经批准的独立标注结果分析 | 先验证授权、双标完成、来源家族隔离和预先固定指标；结果含区间、分歧与失败分析 |

**用户 gate（已决）：** 结构变化与定义保真并列报告；`prep` 为主删除口径、`prep_phrase` 为敏感性分析；采用来源支持的窄类别、有序论元和 unresolved；三轴标签（方向/论元、否定范围、遗漏/添加）加整体判断；既有 40 条只试标，正式样本另行独立抽取。统计单位为义项目标等权，抽中目标包含其全部可审查 OR 分支；先在目标内计算各标签的分支比例，再对目标等权平均；“目标所有分支均保真”另作严格次要指标。分支是目标内重复测量，不作为独立样本。**仍待用户审定：** 可覆盖的来源/总体、盲审中同一内容的多条件呈现方式、置信区间精度目标和资源预算。样本量要在锁定上述项目后按抽样结构推导，不读取正式标签后调整。

### T03 · 知径：现有 Demo 上的可解释概念路径

**问题：** 用户从自己已理解的概念出发，能否找到、比较并检查通往新概念的完整解释路径？

1. 维护现有 `concept-dictionary/`：检查搜索义项、完整 AND 分组、不同 OR 分支、循环/断点提示、来源和未解析边界是否一致。
2. 设计少量固定任务案例：直接定义、多步展开、替代路径、循环/无可用路径、方向/否定介词；每项保存图版本和预期解释结果。
3. Codex 可以做可重复的模拟交互和界面可访问性检查，记录路径错误、误导性提示、状态丢失和移动端问题；模拟用户不能代表真实学习者。
4. 用户体验现有 Demo 后，再决定是否做探索性小样本访谈或正式学习效果实验；后者必须先处理伦理、招募、同意和数据保存。

**PR 节奏：** 仅修一个可验证的用户问题一个 PR，前端代码与原始研究数据分开；新增展示必须对应真实分支和来源。验收通过的是功能，不是学习效果。

### T04 · NLP 应用：先验证 WSD 的结构增益

**问题：** 在候选集、上下文、数据、模型和计算预算公平时，完整构造结构是否让模型更好地区分正确义项，尤其是低频、相近义项和短上下文？

#### T04 阶段与门槛

1. **候选与资源映射（下一执行里程碑）**：候选只从词形、POS 和固定词形变换规则生成；gold 不参与候选选择、分批、排序或补缺。验证 WordNet 3.0—OEWN 2025 映射、重复义项和标签映射；逐目标记录缺映射、标注异常和所有候选数量。
2. **完整候选打包与真实目标定位**：目前完整候选索引覆盖 375/400 train、115/120 dev。PR #31 已实现全候选分块评分及目标级归一化；后续需逐候选记录超预算/编码失败，不得 gold 驱动裁剪。本轮又发现新数据生成器仍取“目标提示 + 整句”前 32 个 WordPiece，句中真实目标可能被截掉；PR #34 已合并：按 XML word position 构造 32-token 目标居中窗口，并用固定词表中的 `[unused0]`/`[unused1]` 标记实际 occurrence；目标无法定位单列失败并保留分母。该变更是输入管线修正，没有真实数据运行或性能结论。
3. **固定共同预算和输入**：A–D 共享目标、经修复的上下文、候选、候选排序、依赖清单与可用预算。A 原 gloss；B 原 gloss + 依赖 gloss；C 在 B 上加成对关系；D 在 B 上保留完整 OR 分支及 AND/角色信息。句子窗口截断与目标定位失败分别统计。结构序列化不得把未出现在语句中的定义前提当作上下文词面必须出现条件。
4. **开发试验与冻结协议分开**：目前 SemCor 76 个 dev 目标是反复用于方案修订的探索集，所有新切分应按文档与来源家族交叉审计。新候选预算 222 和最大总长256已经看过开发覆盖，属于探索参数。训练前冻结新开发方案、模型修订、种子、基线、主要对比和统计计划；先在新来源独立 dev 调试。
5. **确认性评估**：仅当来源/文档隔离、资源映射、候选编码、结构覆盖、token/算力记录、许可与保留测试保护均通过后，解封一次独立评估。主要比较预先指定 D−B；D−C、A−B 与低频/结构相近切片为次要或探索性。按评估目标成对计算差值，并按来源家族 cluster bootstrap（预先固定重采样数与区间）；同时报告三个训练种子分别的结果和覆盖分母。不能把模型种子当独立样本。
6. **现代强基线与扩展**：先完成可重现 gloss 编码基线、MFS/规则基线；外部 LLM 仅在许可、固定版本和成本预算明确后列为对照。若 WSD 没有稳定可解释的增益，缩减结构收益主张并决定停止该配置，不无限调参。只有 WSD 方法过关后，才扩展 FEWS（先做跨资源映射审计）、WiC/WiC-TSV 或 MultiRD 独立人工描述集；反向词典不能替代 WSD。

### T05 · 认知发展：先做数据适配，再做预测

**问题：** 词典依赖中可重复组合和中间概念复用，是否能在控制词频、具体性、词性和普通语义网络后，额外预测义项级习得或理解表现？

1. **数据来源审查**：逐一核对 Wordbank、CHILDES、义项级 AoA 数据的版本、访问条件、许可、下载方式、语言/年龄覆盖和是否有 sense ID。HTE 的词形年代是最早已知引证，不等于概念诞生日；目前公开 pilot 太小，不得批量抓取或并入冻结图。
2. **义项对齐可行性**：先用合法可用的小样本建立词形—POS—义项映射框和双人质量核查；报告精确映射、歧义、无法匹配和年龄度量单位。未能可靠对齐时停止预测建模。
3. **基线优先**：锁定外部目标数据及其训练/验证/测试；先建词频、具体性、POS、语义网络距离/中心性、可用控制变量模型。加入超图中的中间概念复用、定义分支和深度特征时必须仅用训练部分拟合特征处理。
4. **预测而非因果**：报告外部交叉验证/来源分组、增量解释力、校准和区间；测量的平均习得年龄/测试年级有自身限制，不等同个体首次理解时间。计算 cache/reuse 模拟仅是工程或结构指标。
5. **理论结论 gate**：只有可独立复现的外部发展数据增益和测量边界清楚后，才讨论认知解释；因果结论需要有识别策略或适当行为实验，不从词典图单独推出。

**启动条件：** T02/T04 共享协议稳定后，先交付一个不含私密语料的许可与映射可行性 PR；获取许可和外部样本后才开预测工作分支。
