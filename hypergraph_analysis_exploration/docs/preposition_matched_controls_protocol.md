# 精确频数匹配的单批节点删除对照

目的：在目标 head 使用频数相同的前提下，比较一组介词节点与同数量非介词节点被同时移除时的结构变化。这是探索性条件对照，不是随机试验或语义准确率。

冻结输入为 `graph/nodes.tsv`、`graph/hypergraph_rules.jsonl`。使用次数定义为一个节点作为某个目标至少一个分支的直接依赖的目标数；同一目标中多次出现只计一次。介词组为 `pos=prep`，对照为既不是 `prep` 也不是 `prep_phrase` 的节点。每个精确频数层最多取两组较小的节点数；按排序后的 ID、种子 17 无放回抽取固定介词组，再用种子 100–119 在各层无放回抽取 20 组非介词对照。每组节点数和分层使用总次数一致，但目标、来源、分支内容和语义角色不匹配。结果先报告无法匹配的节点及使用次数比例，避免外推到常见高频介词。

对同一完整图分别移除固定介词组和每组对照；以目标为单位，报告至少一条分支改变的目标数、新空分支数和涉及目标数、剩余非空分支发生集合碰撞的目标数和冗余分支数。原分支集合先去重；新空分支不参与非空碰撞。输出记录输入摘要、种子、选中 ID 的摘要、每次结果和对照分布。20 组对照共享同一图和同一介词组，并非 20 个独立语料，不计算因果显著性。节点分组依据 POS 不保证词语语义无关；结果不衡量自然语言含义或正确性。此协议在运行新的匹配对照前固定；上游仅考察了频数匹配覆盖，并未读取此设计的结果。

首轮结果后追加事后敏感性分析：另以 18 和 19 为介词组种子，使用相同的 20 个对照种子。它们仍基于同一词典图和相同频数层，不是独立复现或确认性检验；此额外比较不是原先固定的主要分析。
