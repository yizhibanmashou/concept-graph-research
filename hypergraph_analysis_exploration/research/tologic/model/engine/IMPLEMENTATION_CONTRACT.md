# V3 implementation contract

Internal API shared by the implementation workers. The user-facing authority is specification/RULES.md plus config/structural_relations.json and config/policy.json. Only this new project may be written.

Python 3.11+, standard library only, package src/tologic_v3. Public functions return JSON-compatible dictionaries. Validation returns a list of `{code, path, message}`; an empty list means the local gate passed, never semantic acceptance.

## Source

`{schema_version: "v3.source/1", synset_id, lemmas: [...], definition: string, is_basis: bool, occurrences: [{occurrence_id, text, start: int, end: int, synset_id}], evidence: [...], provenance: {...}}`.
Offsets are Python Unicode character offsets into definition, start inclusive/end exclusive. Completed WSD is authoritative input; never select/repair senses. Source importer may flag missing spans instead of fabricating them. `is_basis` must be checked against frozen basis_ids from the policy context, not trusted from candidate.

## Inventory produced by usage agent

`{synset_id, coverage: {complete: true, rationale: string, evidence_ids: [...]}, usages: [{usage_id, evidence: [string], sentence_a: string, sentence_b: string, argumentation: string, parameters: [{name, type, role}], target_arguments: [string], occurrence_ids: [string], determiners: [{kind: "a"|"the"|"all", occurrence_id, action: "exists"|"parameter"|"share"|"drop"|"provider"|"basis_definition", head_occurrence_id?: string, parameter?: string, antecedent?: string}], voice: "active"|"passive", reductions: [string]}]}`.
Parameters are external/open inputs (including event variable). Target_arguments lists the core target variables, not all role arguments. Definition occurrence_ids account for semantic source; agent must not change WSD. Distinct usages may reduce to same formula. The does not bind: share existing antecedent parameter, or drop only article. All uses its provider, no native forall in nonbasis RHS. `a` can bind a genuinely internal witness, never an external input. Add `witnesses: [{name,type,origin:"a"|"definition_internal",occurrence_id,reason}]` per usage for all allowed RHS existential witnesses; inventory verifier must certify these declarations.

For `a` referring to an already-declared external input, use `action:"parameter"` with that parameter name; do not introduce an existential. `action:"exists"` requires the declared genuinely internal witness.

Each usage also requires `binding_plan:{lexical:[{occurrence_id,usage_id,bindings:{provider_parameter: external_or_witness_name}}],structural:{lhs:[{name,arguments:[variable_name or {implicit_subject:event_variable_name}]}],rhs:[...]}}`. This independent-verifier-certified plan binds external/witness roles before formula generation. Every lexical call matches its plan and all protected argument positions. Structural commitments are side-specific; RHS commitments can be realized by instantiated provider LHS. Meaningful external flow cannot be replaced with tautological x=x. Basis primitive arguments may realize this flow.

Determiner entries must cover every independent a/an/the/all occurrence in the full source, not only usage.occurrence_ids. A usage may additionally declare determiner_exclusions:[{occurrence_id,reason}] (default []); each source determiner must occur exactly once in either determiners or exclusions, with nonempty applicability evidence for exclusions. The independent usage verifier must review those reasons. Excluded occurrences cannot be called lexically. a/the additionally give head_occurrence_id for the actual nominal occurrence. The share/drop always names its external parameter; share requires the same parameter as antecedent. The nominal provider must receive that parameter (or the certified internal witness for a exists). Basis nominal semantics may instead be realized by its primitives and independently reviewed bindings. All may use action basis_definition only for authenticated basis membership; this permits all's own definition without a self-provider. Nonbasis all uses action provider.

## Formula candidate per usage

`{synset_id, usage_id, parameters: [... exact inventory parameters ...], lhs: AST, rhs: AST, primitives: [{name, argument_types:[type], return_type:type, meaning:string, source_evidence:string}], notes:string}`.
Primitives list must be empty outside basis. Only basis may introduce these symbols; declarations travel with accepted formula. No formula-less public primitives or lexical providers. Candidate must not define its own source/usage inventory.

AST: terms `{var: name}`, or `{op:"struct", name:"ImplicitSubj", args:[term]}` (returns E, passive only); formulas `{op:"target", args:[term]}` (own target, LHS only), `{op:"struct",name:"Agent"|"Theme"|"Happen",args:[term]}`, `{op:"use",synset_id,usage_id,provider_hash,occurrence_id,args:[term or lambda or formula]}`; basis primitives `{op:"primitive",name,args:[AST]}`; logical `{op:"and"|"or",args:[AST,...]}`, `{op:"not",body:AST}`, `{op:"implies"|"iff",left:AST,right:AST}`, `{op:"eq",left:term,right:term}`, `{op:"exists"|"forall",variables:[{name,type}],body:AST,origin?:"a"|"definition_internal",occurrence_id?:string}`; `{op:"lambda",parameters:[{name,type}],body:AST}` and `{op:"apply",function:AST,args:[AST]}`. Types are E, V, Time, Prop or `{arrow:[arg_type,...,result_type]}`. No truth/false constants or numeric/literal terms for nonbasis. Basis can use declared zero-arity primitives for constants. forall is basis-only (outer definition parameter closure is metadata, not AST forall).

Provider call is a typed macro: instantiate the complete approved LHS, preserving all roles and sharing; it never denotes a new USE predicate. Recursive semantic expansion then replaces each complete LHS with its certified RHS. Every direct nonbasis use must map to matching definition occurrence. Primitive leakage forbidden in authored nonbasis AST; expanded primitive lineage must terminate at basis.

## Runtime context / module APIs

Context dict: `{policy: dict, structures: dict, basis_ids: [str], providers: {"synset_id::usage_id": provider_record}, round: int, mode:"production"|"demo"}`. Provider record: `{synset_id, usage_id, bundle_hash, round, is_basis, parameters, lhs, rhs, primitives, source, inventory, formula, certificates, mode}`. Source/basis authenticity and hashes are controller-owned.

`gates.py`: `validate_source(source, context)`, `validate_inventory(source, inventory, context)`, `validate_formula(source, inventory, candidate, context)` -> issue lists. `expand_formula(candidate, context, side="rhs")` -> AST (raise ValueError for unresolved calls/capture); preserve namespace of basis primitives during expansion. Gate protects external parameter capture/loss, types, exact source/provider IDs and hashes, earlier rounds, basis membership, allowed structures and passive-only implicit subject, no bare dependency calls, full lhs target + usage parameter coverage. Native forall restricted outside basis; legitimate lambda parameter binding is local and cannot capture external names.

`common.py` (root owns): `canonical_hash(obj)`, `read_json(path)`, `write_json(path,obj)`, `project_root()`, `load_context(project, round_number=0, mode="production")`; strict duplicate/NaN JSON rejection. policy/structure/basis hashes automatically in context. `provider_key(synset_id,usage_id)`.

`pipeline.py` + `backends.py` (worker owns): resumable four-role protocol usage_agent → usage_verifier → per-usage formula_agent → local hard gate → formula_verifier. Independent fresh requests/no shared chat; backend `.generate(role, request)` returns dict. Controller owns request/candidate/context hashes and verifier envelope. Reviews contain `{decision:"ACCEPT"|"REJECT"|"UNRESOLVED", rationale:string, checks:{...}, issues:[...]}`; inventory checks coverage, argumentation, external_parameters, determiners, fixed_wsd; formula checks forward_equivalence, reverse_equivalence, external_parameters, scope, definition_faithfulness. All required checks must be true for ACCEPT. No model-authored verdict can directly publish. Bind certificates to exact source/inventory/formula/context hashes and role request/response execution IDs. Bounded repair attempts, save every outcome; missing providers BLOCKED, malformed output fails closed. Demo/replay certificates must NEVER publish to production. CLI adapter root owns; expose `Pipeline(project, backend, max_attempts=2, mode="production").run(source, context) -> dict` writing staging only, `publish_round(project, runs, context) -> dict` atomic frozen manifest plus derived registry (only complete certified bundles, check/revalidate exact content/hash, no same-round providers, no overwrite, stale context rejection). Production reviewer execution identity independent from agent's call. Credentials only environment variables, never logged. Provide external JSON job backend if practical, plus stdlib HTTP chat-compatible backend explicitly configured from env (no hidden model default).

`importer.py` (docs/import worker owns): import current V2 raw definitions and already-completed WSD as source-only, provenance hashes. Freeze original 85 membership and comparison 521 IDs from V2 explorer historical indexes; no old formulas/interfaces accepted. Prefer canonical source `V2/data/items`, preserve raw WSD alongside normalized occurrences; do not reconstruct absent WSD or silently choose senses. Ambiguous/missing alignment flags blocked source. CLI root integrates functions after worker reports names.

Docs/import worker owns specification/, skills/ (4 SKILL.md), config/structural_relations.json, config/policy.json, importer.py, importer-specific tests. Gates worker owns gates.py + gate-specific tests. Pipeline worker owns pipeline.py/backends.py + pipeline-specific tests. Root owns common.py, cli.py, examples, shared tests, package setup, README, integration. Do not change another worker's files without coordination.
